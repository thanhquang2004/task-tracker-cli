# 📝 Task Tracker CLI
Project: https://roadmap.sh/projects/task-tracker

A simple, command-line interface (CLI) application built with Python to help you track and manage your daily tasks. This project was developed as a practice exercise to master file systems, JSON handling, and CLI argument parsing.

---

## 🚀 Features

- **Add Tasks**: Create new tasks with an automatic unique ID and timestamps.
- **Update Tasks**: Modify the description of existing tasks.
- **Delete Tasks**: Remove tasks from your list permanently.
- **Status Management**: Mark tasks as `todo`, `in-progress`, or `done`.
- **Filtered Listing**: 
  - View all tasks.
  - View only completed tasks (`done`).
  - View tasks currently being worked on (`in-progress`).
  - View tasks yet to be started (`todo`).

---

## 🛠️ Installation

1. **Clone the repository** (or copy the script):
   ```bash
   git clone [https://github.com/your-username/task-tracker-python.git](https://github.com/your-username/task-tracker-python.git)
   cd task-tracker-python
   ```

2. **Ensure you have Python installed**:
    ```bash
    python --version  # Recommended: Python 3.10 or higher
    ```

3. **Run the script**:

    No external libraries are required. The script uses only built-in Python modules.
